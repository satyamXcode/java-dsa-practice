# Java & DSA Practice

A structured repository to learn and practise **Core Java, Data Structures, and Algorithms** through hands-on coding.

## Learning Goals

- Strengthen Core Java fundamentals.
- Understand object-oriented programming concepts.
- Improve problem-solving and logical thinking.
- Learn important data structures and algorithms.
- Prepare for Java developer technical interviews.

2. Open the project in IntelliJ IDEA.
3. Configure JDK 21.
4. Open the required Java class.
5. Run the `main()` method.
